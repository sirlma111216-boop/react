# 설계·밸런스 결정 기록

형식: 결정 → 이유 → 전후 값 → 근거 종류(과학/기술/시뮬레이션/제품).

## 제품·규칙

1. **계약 확보를 계획+실행 단계 모두 허용** (원안: 계획 단계만). 실행 중 생산 상황을 보고 계약을 잡는 편이 초보 팀의 막힘을 줄인다. 취소는 계획 단계만, 취소한 라운드에는 새 확보 불가(첫 계약 예외). — 제품.
2. **고체 원료의 수용액 반응(R07·R09)은 공정 용수를 명시적으로 유입해 용해**하고 용매 원장에 기록. 별도 "용해" 행동을 만들면 5행동 원칙과 5분 첫 성공 목표를 해친다. — 기술/과학(보존 유지).
3. **반응 산출은 '스트림'으로 정의**(순물질 로트 또는 혼합물 로트). R04·R06 의 기체 혼합물, R07·R13·R16·R18 의 현탁액, R20·R22 의 부분 전환 잔류물이 모두 같은 구조로 표현되어 새 반응 추가 시 UI·서버를 바꾸지 않는다. — 기술.
4. **로트 병합 규칙**: 물질·등급·태그·이력 체인이 같은 순물질만 합친다. 구매 물질을 생산 로트에 섞어 세탁할 수 없다. — 경제.
5. **조작 담당자 이탈 15초 유예**는 서버 알람으로 처리하고, 교사는 언제든 조작권을 넘길 수 있다. — 제품.
6. **경기 중 신규 입장은 관전자**, 교사가 팀에 편입해도 자원 추가 지급 없음. — 제품.
7. **교사 팀 참가**: 교사가 새 팀의 팀장으로 참가할 수 있고, 보드는 "관전 보드 ↔ 내 팀 보드"로 전환. — 제품(사용자 요구).
8. **개발 환경에서만 타이머 배율 0.05 허용**(`ENVIRONMENT !== 'production'`) — 통합 테스트가 6라운드를 1분 안에 완주하기 위함. 운영은 0.75~2. — 기술.
9. **연습 모드는 브라우저 안에서 같은 엔진**을 돌리고 AI 팀은 다단계 계획 봇을 사용. 서버 없이 3분 안에 한 주문 완료 가능. — 제품.
10. **팀 간 거래·채팅 없음** — 통합 프롬프트의 범위 결정 그대로. — 제품.

## 과학 (변경 금지 영역에서의 명확화)

- R03 생성 물은 `solutionWater`(회수 등급)로 두어 정제수 계약(C01: `condensed`/`refined`)에 쓰이지 않게 했다.
- R10·R11 에서 생성된 물은 용액 용매에 합산(원소 보존 검사에 포함).
- R20·R22 의 50% 전환은 게임 모델이며 촉매는 시간만 단축한다. 카드에 명시.
- P01 은 비응축 기체가 두 종 이상이면 임의 분리하지 않는다(현재 콘텐츠에는 해당 경우 없음).
