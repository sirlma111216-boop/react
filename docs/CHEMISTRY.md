# 과학 데이터·단순화·출처

과학 데이터 버전 `chem-1.0` (`src/shared/chemistry/`). 이 문서는 게임이 지키는 법칙, 의도적 단순화, 출처를 적습니다. 게임의 라운드·에너지·코인은 추상 비용이며 실제 반응 속도·반응열·시세가 아닙니다.

## 지키는 것 (변경 금지)

1. **질량(원소) 보존** — 모든 반응·공정·납품·구매·용매 유입을 원소 단위 원장으로 기록하고, `verifyTeamLedger` 가 매 정산마다 `유입 − 유출 = 보유`를 검사합니다(시뮬레이터·테스트). 기체가 나갔다고 사라지지 않습니다. 가열 에너지는 질량 토큰이 아닙니다.
2. **일정 성분비** — 순수 화합물의 원소 질량비는 조성에서 고정됩니다(H=1, C=12, N=14, O=16, Na=23, Mg=24, S=32, Cl=35.5, Ca=40, Mn=55, Fe=56, Cu=63.5, Zn=65 교육용 반올림 원자량 한 체계만 사용). 물 H:O = 1:8.
3. **기체 반응 법칙** — 동일 온도·압력의 기체끼리만 부피비를 표시합니다(R01, R02, R04, R19 반응물, R20). 액체 물에는 부피비를 붙이지 않습니다. R20 은 "동일 조건으로 환산한 이상기체 기준"으로 한정합니다.
4. **분류** — `compositionClass`(홑원소/화합물/혼합물)와 `structureClass`(분자/이온/금속/그물)를 별도 필드로 둡니다. NaCl(s)는 Na⁺:Cl⁻ 1:1 격자, CaCl₂ 는 1:2 로 그립니다. "NaCl 분자"라는 표현은 쓰지 않습니다.
5. **상태 구분** — HCl(g)≠HCl(aq), H₂O(g)≠H₂O(l), NaCl(aq)≠NaCl(s). 이름이 같아도 상태별 재고를 합치지 않습니다.
6. **촉매** — 재사용 장비이며 소모되지 않고, 시간만 줄이며 전환량·평형은 바꾸지 않습니다(U08 MnO₂, U09 Fe, U10 산). Fe(s) 원료와 Fe 촉매 모듈은 다른 재고입니다.

## 재고 단위와 용매 원장

- 1칸 = 0.1 mol (내부 정수). 질량은 화학식×원자량×mol 로 계산합니다.
- 수용액 원료 1칸은 용질 0.1 mol + **운반 용매 1칸**(공정 용수)입니다. 용매는 판매 가능한 순수 물이 아니며 별도 `solvent` 필드와 팀 `solventLedger`(유입·회수·폐기)로 추적합니다.
- 고체 원료를 수용액 반응(R07, R09)에 넣을 때는 공정 용수를 명시적으로 유입시킵니다(원장 기록). 중화(R10) 등에서 생성된 물은 용액의 용매에 합산됩니다.
- 결정화(P03)·정제(P04 R21)에서 분리된 용매는 회수수로 돌아갑니다.

## 가공 4종

- **P01 응축·기체 회수**: 수증기→액체 물(`condensed`), 비응축 기체가 한 종이면 회수(`gasCollected`), 두 종 이상이면 임의 분리하지 않고 기체 혼합물로 남김.
- **P02 고체 회수**: 여과·세척·건조를 하나의 공정으로. 불용성 고체 한 종만 회수(`filtered`), 용해 염은 여액(`filtrate`, 회수 등급)으로. 고체가 두 종이면 미지원.
- **P03 염 결정화**: NaCl(aq) 단일 용액만(`crystallized`). 수화물이 생기는 염은 이번 완성판에서 대상 아님.
- **P04 산업 정제**(U07): R20 → NH₃ 분리 + N₂/H₂ 회수(재투입 가능, 새 공정으로 다시 비용 소모), R21 → 에탄올(정제 등급), R22 → 에스터 분리 + 미반응물 회수. 그 밖의 로트는 "recipe 미정의"로 거절.

## 원소 수 일치 ≠ 실제 가능

원소 수 보존은 반응이 실제로 일어난다는 충분조건이 아닙니다. 위 표의 조건·출처는 교육 자료 수준의 검토이며, 실제 실험 지침이 아닙니다. 조건 밖의 조합은 "이 공방에서 지원하지 않는 공정"으로 표시하며 "현실에서 반응하지 않음"이라고 단정하지 않습니다.
